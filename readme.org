Course materials for Systems and Toolchains for AI Engineers, Fall 2026.

*The rendered site is public:*
https://kitchingroup.cheme.cmu.edu/f26-06763/

Anything listed in the ~toc:~ of ~_toc.yml~ is published to that site. Anything
not listed stays private, which is why ~course/modules/~ (instructor planning and
teaching notes) is deliberately excluded.

* Structure

| Path                     | What it is                                        |
|--------------------------+---------------------------------------------------|
| ~CLAUDE.md~              | Working conventions. Read this first.             |
| ~course/~                | Planning material: syllabus, schedule, modules, assignments |
| ~lectures/lNN/~          | Per-session notes, slides, and demo notebook      |
| ~_templates/~            | Skeletons for notes and slides                    |
| ~themes/course.css~      | Shared MARP slide theme                           |
| ~_toc.yml~               | Jupyter Book config and table of contents         |

One directory per session, ~l01~ through ~l22~, matching the L-numbers in
~course/schedule.md~. ~lectures/l01/~ is the worked reference for both formats.

* Building using jupyter-books and MARP.

#+begin_src sh
pip install "jupyter-book<2"  # 1.x is required, see CLAUDE.md section 8
jupyter-book build .          # full book into _build/html

npx @marp-team/marp-cli lectures/l01/slides.md -o /tmp/l01.html
#+end_src

Pushing to ~main~ builds the book, renders every slide deck, and deploys to
GitHub Pages via ~.github/workflows/book.yml~.

* Conventions

Lecture notes are "textbook" documents/chapters meant to be read outside class. Slides are for presentation of the content during lectures. They are separate artifacts with
separate jobs, both derived from the corresponding lecture block in
~course/modules/wkNN.md~. The full orchestraton is in [[file:CLAUDE.md][CLAUDE.md]].
