Arcade, against a local Worker

A development harness, not a published page. It talks to localhost:8787, so it needs both halves running: cd clicker && npx wrangler dev --local and, from the repository root, python3 -m http.server 8080 — then open http://127.0.0.1:8080/arcade/local.html. Opening this file directly as file:// will not work: the round file is fetched, and a file:// page is not allowed to.

This is the notes-page embed: data-board="all", so it ranks each player's best run of the whole semester. A slide uses data-board="live" instead. See arcade/demo.md for that one.
