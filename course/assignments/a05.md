## The bioreactor

```{figure} figures/a05-reactor.png
:alt: A stirred bioreactor. A blue arrow labeled feed F in cubic meters per second with substrate S_F enters the top. An orange arrow labeled outflow F with X and S leaves through the right wall. Labels point to the cells (biomass X), the liquid (substrate S) and the liquid level (volume V, constant, in equals out).
:width: 75%

The feed enters at rate $F$ with substrate concentration $S_F$. The outflow leaves at the same rate, at the reactor concentrations $X$ and $S$, so the volume $V$ is constant.
```

The model is two mass balances, one for the biomass $X$ and one for the substrate $S$:

$$
\frac{dX}{dt} = \underbrace{-\frac{F}{V}\,X}_{\text{outflow}} + \underbrace{\mu(S)\,X}_{\text{growth}}
$$

$$
\frac{dS}{dt} = \underbrace{\frac{F}{V}\,(S_F - S)}_{\text{feed} - \text{outflow}} - \underbrace{\frac{\mu(S)}{Y(S)}\,X}_{\text{consumption}}
$$

with the specific growth rate $\mu(S)$ and the yield $Y(S)$:

$$
\mu(S) = 10^{-3}\,S\,e^{-S/120}, \qquad Y(S) = 5.4 \cdot 10^{-3} + 1.8 \cdot 10^{-4}\,S
$$

| Symbol | Meaning | Value | Units |
|---|---|---|---|
| $X$ | Biomass concentration | state | kg/m³ |
| $S$ | Substrate concentration | state | mol/m³ |
| $\mu(S)$ | Specific growth rate | equation above | 1/s |
| $Y(S)$ | Yield: biomass made per substrate consumed | equation above | kg/mol |
| $V$ | Reactor volume | $\pi \cdot 3^2 \cdot 5.7$; in code `np.pi * 3**2 * 5.7` | m³ |
| $F$ | Feed and outflow rate | 5.02597 | m³/s |
| $S_F$ | Substrate concentration in the feed | 300 | mol/m³ |

### Task 1. Discrete-time model
Predict the next sample from the current one:

$$
\begin{bmatrix} X \\ S \end{bmatrix}_{k+1} = f\left(\begin{bmatrix} X \\ S \end{bmatrix}_k\right)
$$

1. Build the training pairs $(x_k, x_{k+1})$ from experiments 1 to 4: 60 pairs per experiment, 240 in total. Keep each pair inside one experiment (L7, "The first row of a run").
2. Fit $f$ with `make_pipeline(StandardScaler(), Ridge(alpha=1.0))` (scikit-learn; L8). `Ridge` fits both outputs, $X$ and $S$, at once.
3. Simulate experiment 5 recursively (L8, "Direct and recursive forecasting"): start from $x_0 = (3.0, 80)$ and apply $f$ 60 times, feeding each prediction back in.

### Task 2. PINN
A network maps time to the two states, $t \mapsto (X_\text{NN}, S_\text{NN})$. Train it for experiment 5 only. Its data is the initial condition; its physics is the residual of both balances at the collocation points $t_j$:

$$
r_X = \frac{dX_\text{NN}}{dt} + \frac{F}{V}\,X_\text{NN} - \mu(S_\text{NN})\,X_\text{NN}
$$

$$
r_S = \frac{dS_\text{NN}}{dt} - \frac{F}{V}\,(S_F - S_\text{NN}) + \frac{\mu(S_\text{NN})}{Y(S_\text{NN})}\,X_\text{NN}
$$

$$
\mathcal{L}_\text{data} = \frac{1}{2}\left[\left(\frac{X_\text{NN}(0) - X_0}{X_\text{scale}}\right)^2 + \left(\frac{S_\text{NN}(0) - S_0}{S_\text{scale}}\right)^2\right]
$$

$$
\mathcal{L}_\text{physics} = \frac{1}{301} \sum_{j=1}^{301} \left(r_X(t_j)^2 + r_S(t_j)^2\right)
\qquad
\mathcal{L} = \mathcal{L}_\text{data} + \lambda\,\mathcal{L}_\text{physics}
$$

| Setting | Value |
|---|---|
| Network | 3 hidden layers of 32 tanh units, initialized with `jax.random.PRNGKey(0)` (JAX; L13) |
| Collocation points | 301, evenly spaced from 0 to 300 s |
| $\lambda$ | 0.01 |
| Optimizer | `optax.adam(1e-3)` (Optax; L11, L13), 20,000 steps |

The network and the time derivatives. Use this code: the outputs are scaled to order one and kept positive with `jax.nn.softplus` (JAX; L13), and `jax.grad` (JAX; L11, L13) needs a function with one output, so there is one function per state.

```python
T_SCALE = 300.0                  # s
X_SCALE, S_SCALE = 5.0, 100.0    # kg/m3, mol/m3
SCALE = jnp.array([X_SCALE, S_SCALE])


def net(params, t):
    h = t[:, None] / T_SCALE
    for W, b in params[:-1]:
        h = jnp.tanh(h @ W + b)
    W, b = params[-1]
    return jax.nn.softplus(h @ W + b) * SCALE    # X and S, never negative


def X_nn(params, t):
    return net(params, jnp.array([t]))[0, 0]


def S_nn(params, t):
    return net(params, jnp.array([t]))[0, 1]


dX = jax.grad(X_nn, argnums=1)    # dX/dt
dS = jax.grad(S_nn, argnums=1)    # dS/dt
```

1. Write $r_X$ and $r_S$ at the collocation points, with `jax.vmap` (JAX; L11, L13) over $t_j$. Multiply $r_X$ by `T_SCALE / X_SCALE` and $r_S$ by `T_SCALE / S_SCALE`, so both are of order one.
2. Write $\mathcal{L}$ and train with the settings above, as in `l13-pinn-jax.ipynb`.
3. Evaluate the trained network on the time grid.

### Task 3. Neural ODE
Keep the balances and $Y(S)$. Replace $\mu(S)$ with a network $\mu_\text{NN}(S)$, learned from experiments 1 to 4:

$$
\frac{dX}{dt} = -\frac{F}{V}\,X + \mu_\text{NN}(S)\,X, \qquad
\frac{dS}{dt} = \frac{F}{V}\,(S_F - S) - \frac{\mu_\text{NN}(S)}{Y(S)}\,X
$$

Use this network and optimizer. `GrowthRate` is the class of `l13-neural-dae.ipynb`, with $S$ as its only input.

- Taught in L13: `eqx.Module` and `eqx.nn.MLP` (Equinox), `optax.cosine_decay_schedule` (Optax).
- New, given in full: `eqx.tree_at` (Equinox; [docs](https://docs.kidger.site/equinox/api/manipulation/)) sets the last layer to zero, so training starts from a constant $\mu$. `optax.chain` and `optax.clip_by_global_norm` (Optax; [docs](https://optax.readthedocs.io/en/latest/api/transformations.html)) cap the size of each step.

```python
mu_scale = 0.05      # 1/s: sets the size of mu


class GrowthRate(eqx.Module):
    mlp: eqx.nn.MLP

    def __call__(self, S):
        out = self.mlp(jnp.array([S / 100.0]))[0]
        return mu_scale * jax.nn.softplus(out)    # mu >= 0


mlp = eqx.nn.MLP(
    in_size=1,
    out_size=1,
    width_size=16,
    depth=2,
    activation=jnp.tanh,
    key=jax.random.PRNGKey(0),
)
last = mlp.layers[-1]
mlp = eqx.tree_at(
    lambda m: (m.layers[-1].weight, m.layers[-1].bias),
    mlp,
    (jnp.zeros_like(last.weight), jnp.zeros_like(last.bias)),
)
mu_net = GrowthRate(mlp)

schedule = optax.cosine_decay_schedule(
    init_value=1e-2,
    decay_steps=5_000,
    alpha=0.05,
)
opt = optax.chain(
    optax.clip_by_global_norm(1.0),
    optax.adam(schedule),
)
```

1. Write the balances with $\mu_\text{NN}$. Evaluate $\mu_\text{NN}$ and $Y$ at `jnp.maximum(S, 0.0)` (JAX; new, [docs](https://docs.jax.dev/en/latest/_autosummary/jax.numpy.maximum.html)): during training $S$ can go negative, $Y(S)$ reaches zero, and the solver stops.
2. Simulate with `diffrax.diffeqsolve` (Diffrax; L13), using `diffrax.Tsit5()`, `dt0=0.5` and `diffrax.PIDController(rtol=1e-6, atol=1e-8)`.
3. Train on experiments 1 to 4 for 5,000 steps, as in `l13-neural-dae.ipynb` (`eqx.filter_value_and_grad` and `eqx.filter_jit`; Equinox; L13). Loss: the mean of $\left((\text{prediction} - \text{data}) / \sigma\right)^2$ over all samples of the four experiments, where $\sigma$ is the standard deviation of the training data of $X$ and of $S$.
4. Predict experiment 5 from its initial condition. No retraining.
5. Evaluate $\mu_\text{NN}$ at $S = 10, 15, \ldots, 130$ mol/m³.

### Task 4. Compare
The error of a prediction $\hat{y}$ against the 61 measurements $y$ of experiment 5 is the root mean square error (RMSE):

$$
\text{RMSE} = \sqrt{\frac{1}{61} \sum_{k=1}^{61} \left(\hat{y}_k - y_k\right)^2}
$$

The measurement noise sets a floor: no model can score much below 0.05 kg/m³ on $X$ or 1 mol/m³ on $S$.
