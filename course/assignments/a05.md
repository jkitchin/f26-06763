## The bioreactor
The model has two states: the biomass concentration $X$ (kg/m³) and the substrate concentration $S$ (mol/m³). Each balance reads accumulation = in − out + made − used:

$$
\frac{dX}{dt} = \underbrace{-\frac{F}{V}\,X}_{\text{leaves with the outflow}} + \underbrace{\mu(S)\,X}_{\text{growth}}
$$

$$
\frac{dS}{dt} = \underbrace{\frac{F}{V}\,(S_F - S)}_{\text{fed in, minus the outflow}} - \underbrace{\sigma(S)\,X}_{\text{eaten by the cells}}
$$

The kinetics are

$$
\mu(S) = 10^{-3}\,S\,e^{-S/120}, \qquad \sigma(S) = \frac{\mu(S)}{Y(S)}, \qquad Y(S) = 5.4 \cdot 10^{-3} + 1.8 \cdot 10^{-4}\,S
$$

- $\mu(S)$ is the specific growth rate (1/s). It rises with $S$ up to $S = 120$ mol/m³, then falls: too much substrate slows the cells down.
- $\sigma(S)$ is the specific substrate consumption rate (mol of substrate per kg of cells per second).
- $Y(S)$ is the yield: kg of cells made per mol of substrate eaten.

| Parameter | Value |
|---|---|
| Volume $V$ | $\pi \cdot (3\ \text{m})^2 \cdot 5.7\ \text{m}$; in code, `V = np.pi * 3**2 * 5.7`, not a rounded number |
| Feed rate $F$ | 5.02597 m³/s |
| Substrate in the feed $S_F$ | 300 mol/m³ |
| Steady state | $X^* = 3.46198$ kg/m³, $S^* = 45.6033$ mol/m³ |

Here, as in the Lecture 13 worked example, the true kinetics make the measurements and check your results. The PINN uses the whole model. **The neural ODE does not see $\mu(S)$: it has to learn it from the data.**

### 3. A PINN
The PINN maps time to the two states, $t \mapsto \left(X_\text{NN}(t),\ S_\text{NN}(t)\right)$. Its physics loss uses the residual of each balance at the collocation points $t_j$:

$$
r_X(t_j) = \frac{dX_\text{NN}}{dt} + \frac{F}{V}\,X_\text{NN} - \mu(S_\text{NN})\,X_\text{NN}
$$

$$
r_S(t_j) = \frac{dS_\text{NN}}{dt} - \frac{F}{V}\,(S_F - S_\text{NN}) + \sigma(S_\text{NN})\,X_\text{NN}
$$

$$
\mathcal{L} = \mathcal{L}_\text{data} + \lambda\,\mathcal{L}_\text{physics}
$$

a) Write the network, the two residuals and the two losses, following `l13-pinn-jax.ipynb`. Use `jax.grad` for the time derivatives, as the worked example does. The physics loss averages $r_X^2 + r_S^2$ over the collocation points.

Hint: time runs to 300 s and $S$ goes up to about 135 mol/m³, so scale the input and the outputs. Keep the outputs positive with a softplus, the same trick `GrowthRate` uses in `l13-neural-dae.ipynb`:

```python
T_SCALE = 300.0                  # s
X_SCALE, S_SCALE = 5.0, 100.0    # kg/m3, mol/m3
SCALE = jnp.array([X_SCALE, S_SCALE])


def net(params, t):
    h = t[:, None] / T_SCALE
    for W, b in params[:-1]:
        h = jnp.tanh(h @ W + b)
    W, b = params[-1]
    return jax.nn.softplus(h @ W + b) * SCALE    # X and S, never negative
```

`jax.grad` needs a function that returns one number, so write one per state, as `x_nn` does in the worked example:

```python
def X_nn(params, t):
    return net(params, jnp.array([t]))[0, 0]


def S_nn(params, t):
    return net(params, jnp.array([t]))[0, 1]


dX = jax.grad(X_nn, argnums=1)     # dX/dt
dS = jax.grad(S_nn, argnums=1)     # dS/dt
```

Multiply $r_X$ by `T_SCALE / X_SCALE` and $r_S$ by `T_SCALE / S_SCALE`, and divide the data error by `SCALE`, so every term in the loss is of order one.

b) Train a PINN on run 1, with its 61 measurements as the data.

### 4. A neural ODE that learns the kinetics
Now pretend you do not know $\mu(S)$. Keep the balances and the yield $Y(S)$, and let a network learn the growth rate:

$$
\frac{dX}{dt} = -\frac{F}{V}\,X + \mu_\text{NN}(S)\,X
$$

$$
\frac{dS}{dt} = \frac{F}{V}\,(S_F - S) - \frac{\mu_\text{NN}(S)}{Y(S)}\,X
$$

a) Write the network and the balances, following `l13-neural-dae.ipynb`. Here $\mu$ depends on $S$ only:

```python
mu_scale = 0.05      # 1/s: sets the size of mu


class GrowthRate(eqx.Module):
    mlp: eqx.nn.MLP

    def __call__(self, S):
        out = self.mlp(jnp.array([S / 100.0]))[0]    # any real number
        return mu_scale * jax.nn.softplus(out)       # mu >= 0
```

Hint: inside the balances, evaluate the kinetics at `jnp.maximum(S, 0.0)`. A bad training step can push $S$ below zero, where $Y(S)$ goes to zero, and the solver stops with "The maximum number of solver steps was reached."

b) Train it on runs 1 to 4 together, the sequential way: simulate the four runs with `diffeqsolve`, compare with the data, and update the weights. Two changes to the worked example make the training reliable:

```python
mlp = eqx.nn.MLP(
    in_size=1,
    out_size=1,
    width_size=16,
    depth=2,
    activation=jnp.tanh,
    key=jax.random.PRNGKey(0),
)

# 1. Start the last layer at zero, so training starts from a constant mu.
mlp = eqx.tree_at(
    lambda m: (m.layers[-1].weight, m.layers[-1].bias),
    mlp,
    (jnp.zeros_like(mlp.layers[-1].weight), jnp.zeros_like(mlp.layers[-1].bias)),
)
mu_net = GrowthRate(mlp)

# 2. Clip the gradient, so one bad step cannot throw the training off.
schedule = optax.cosine_decay_schedule(
    init_value=1e-2,
    decay_steps=5_000,
    alpha=0.05,
)
opt = optax.chain(
    optax.clip_by_global_norm(1.0),
    optax.adam(schedule),
)
```

c) Evaluate $\mu_\text{NN}$ at $S = 10, 15, \ldots, 130$ and save it to `results/mu.csv`. Plot it against the true $\mu(S)$. Where do they agree? Where do they not, and why? Compare $\mu_\text{NN}(S^*)$ with $F/V$ from 1(b).
