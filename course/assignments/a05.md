Consider a continuous bioreactor in which the biomass (cells) grows by consuming substrate. You have noisy measurements of four start-ups. Use them to build three models, and predict a fifth start-up with each one:

1. A **discrete-time model**, as in [Lecture 7](../../lectures/l07/notes.md) and [Lecture 8](../../lectures/l08/notes.md).
2. A **physics-informed neural network (PINN)**, as in [Lecture 13](../../lectures/l13/notes.md) and [`l13-pinn-jax.ipynb`](../../lectures/l13/l13-pinn-jax.ipynb).
3. A **neural ODE** (ordinary differential equation) that learns the growth rate, as in [Lecture 13](../../lectures/l13/notes.md) and [`l13-neural-dae.ipynb`](../../lectures/l13/l13-neural-dae.ipynb).

## The bioreactor

$$
\frac{dX}{dt} = -\frac{F}{V}\,X + \mu(S)\,X
$$

$$
\frac{dS}{dt} = \frac{F}{V}\,(S_F - S) - \frac{\mu(S)}{Y(S)}\,X
$$

$$
\mu(S) = 10^{-3}\,S\,e^{-S/120}, \qquad Y(S) = 5.4 \cdot 10^{-3} + 1.8 \cdot 10^{-4}\,S
$$

- $X$ is the biomass (kg/m³) and $S$ the substrate (mol/m³).
- $\mu(S)$ is the growth rate (1/s), and $Y(S)$ the yield (kg of cells per mol of substrate).
- $V = \pi \cdot 3^2 \cdot 5.7$ m³ (in code, `np.pi * 3**2 * 5.7`), $F = 5.02597$ m³/s and $S_F = 300$ mol/m³.

## Tasks

### 1. The true model

### 2. A discrete-time model
Predict the next sample from the current one:

$$
\begin{bmatrix} X \\ S \end{bmatrix}_{k+1} = f\left(\begin{bmatrix} X \\ S \end{bmatrix}_k\right)
$$

Fit $f$ with `make_pipeline(StandardScaler(), Ridge(alpha=1.0))` on every pair of consecutive samples of runs 1 to 4. Keep each pair inside its run. Then simulate run 5: start from its initial condition and feed each prediction back in, 60 times.

### 3. A PINN
Train a PINN for run 5, following `l13-pinn-jax.ipynb`. Its only data point is the initial condition. Its physics loss is the mean of $r_X^2 + r_S^2$ at 301 collocation points from 0 to 300 s:

$$
r_X = \frac{dX_\text{NN}}{dt} + \frac{F}{V}\,X_\text{NN} - \mu(S_\text{NN})\,X_\text{NN}
$$

$$
r_S = \frac{dS_\text{NN}}{dt} - \frac{F}{V}\,(S_F - S_\text{NN}) + \frac{\mu(S_\text{NN})}{Y(S_\text{NN})}\,X_\text{NN}
$$

Use 3 hidden layers of 32 tanh units, `jax.random.PRNGKey(0)`, `optax.adam(1e-3)` for 20,000 steps, and $\lambda = 0.01$. Time runs to 300 s and $S$ to about 135 mol/m³, so scale the input and the outputs:

```python
T_SCALE = 300.0                  # s
X_SCALE, S_SCALE = 5.0, 100.0    # kg/m3, mol/m3
SCALE = jnp.array([X_SCALE, S_SCALE])


def net(params, t):
    h = t[:, None] / T_SCALE
    for W, b in params[:-1]:
        h = jnp.tanh(h @ W + b)
    W, b = params[-1]
    return jax.nn.softplus(h @ W + b) * SCALE    # X and S, never negative


def X_nn(params, t):                             # jax.grad needs one output
    return net(params, jnp.array([t]))[0, 0]


def S_nn(params, t):
    return net(params, jnp.array([t]))[0, 1]
```

Hint: multiply $r_X$ by `T_SCALE / X_SCALE` and $r_S$ by `T_SCALE / S_SCALE`, and divide the data error by `SCALE`, so every term of the loss is of order one.

### 4. A neural ODE
Now pretend you do not know $\mu(S)$. Keep the balances and $Y(S)$, and learn $\mu$ with a network from runs 1 to 4, the sequential way of `l13-neural-dae.ipynb`. Then predict run 5 from its initial condition. Use this network and optimizer:

```python
mu_scale = 0.05      # 1/s: sets the size of mu


class GrowthRate(eqx.Module):
    mlp: eqx.nn.MLP

    def __call__(self, S):
        out = self.mlp(jnp.array([S / 100.0]))[0]
        return mu_scale * jax.nn.softplus(out)    # mu >= 0


mlp = eqx.nn.MLP(
    in_size=1,
    out_size=1,
    width_size=16,
    depth=2,
    activation=jnp.tanh,
    key=jax.random.PRNGKey(0),
)
# Start the last layer at zero.
last = mlp.layers[-1]
mlp = eqx.tree_at(
    lambda m: (m.layers[-1].weight, m.layers[-1].bias),
    mlp,
    (jnp.zeros_like(last.weight), jnp.zeros_like(last.bias)),
)
mu_net = GrowthRate(mlp)

schedule = optax.cosine_decay_schedule(
    init_value=1e-2,
    decay_steps=5_000,
    alpha=0.05,
)
opt = optax.chain(
    optax.clip_by_global_norm(1.0),    # cap the size of each step
    optax.adam(schedule),
)
```

Train for 5,000 steps. Solve with `diffrax.Tsit5()`, `dt0=0.5` and `PIDController(rtol=1e-6, atol=1e-8)`, and divide the error by the standard deviation of the data, as the worked example does.

Hint: inside the balances, use `jnp.maximum(S, 0.0)` in $\mu$ and $Y$. A bad step can push $S$ below zero, where $Y(S)$ reaches zero, and the solver stops with "The maximum number of solver steps was reached."
