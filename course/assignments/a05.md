## The bioreactor

```{figure} figures/a05-reactor.png
:alt: A stirred bioreactor. A blue arrow labeled feed F in cubic meters per second with substrate S_F enters the top. An orange arrow labeled outflow F with X and S leaves through the right wall. Labels point to the cells (biomass X), the liquid (substrate S) and the liquid level (volume V, constant, in equals out).
:width: 75%

The feed enters at rate $F$ with substrate concentration $S_F$. The outflow leaves at the same rate, at the reactor concentrations $X$ and $S$, so the volume $V$ is constant.
```

The model consists of two dynamic mass balances, one for the biomass $X$ and one for the substrate $S$:

$$
\frac{dX}{dt} = \underbrace{-\frac{F}{V}\,X}_{\text{outflow}} + \underbrace{\mu(S)\,X}_{\text{growth}}
$$

$$
\frac{dS}{dt} = \underbrace{\frac{F}{V}\,(S_F - S)}_{\text{feed} - \text{outflow}} - \underbrace{\frac{\mu(S)}{Y(S)}\,X}_{\text{consumption}}
$$

where $\mu(S)$ is the specific growth rate and $Y(S)$ the yield:

$$
\mu(S) = 10^{-3}\,S\,e^{-S/120}, \qquad Y(S) = 5.4 \cdot 10^{-3} + 1.8 \cdot 10^{-4}\,S
$$

| Symbol | Meaning | Value | Units |
|---|---|---|---|
| $X$ | Biomass concentration | state | kg/m³ |
| $S$ | Substrate concentration | state | mol/m³ |
| $\mu(S)$ | Specific growth rate | equation above | 1/s |
| $Y(S)$ | Yield: biomass made per substrate consumed | equation above | kg/mol |
| $V$ | Reactor volume | $\pi \cdot 3^2 \cdot 5.7$; in code `np.pi * 3**2 * 5.7` | m³ |
| $F$ | Feed and outflow rate | 5.02597 | m³/s |
| $S_F$ | Substrate concentration in the feed | 300 | mol/m³ |

## 2. PINN
Consider a network that maps time to the two states, $t \mapsto (X_\text{NN}, S_\text{NN})$. Its physics loss is the residual of the two balances at the collocation points $t_j$:

$$
r_X = \frac{dX_\text{NN}}{dt} + \frac{F}{V}\,X_\text{NN} - \mu(S_\text{NN})\,X_\text{NN}
$$

$$
r_S = \frac{dS_\text{NN}}{dt} - \frac{F}{V}\,(S_F - S_\text{NN}) + \frac{\mu(S_\text{NN})}{Y(S_\text{NN})}\,X_\text{NN}
$$

Its data loss is the error at the initial condition, the only data point:

$$
\mathcal{L}_\text{data} = \frac{1}{2}\left[\left(\frac{X_\text{NN}(0) - X_0}{X_\text{scale}}\right)^2 + \left(\frac{S_\text{NN}(0) - S_0}{S_\text{scale}}\right)^2\right]
$$

$$
\mathcal{L}_\text{physics} = \frac{1}{301} \sum_{j=1}^{301} \left(r_X(t_j)^2 + r_S(t_j)^2\right)
$$

$$
\mathcal{L} = \mathcal{L}_\text{data} + \lambda\,\mathcal{L}_\text{physics}
$$

Using JAX and Optax, as in `l13-pinn-jax.ipynb`, train a PINN for experiment 5:

a) Code the network below: 3 hidden layers of 32 tanh units. It scales the outputs to order one and keeps them positive with `jax.nn.softplus` (JAX; L13). `jax.grad` (JAX; L11, L13) needs a function with one output, so there is one function per state.

```python
T_SCALE = 300.0                  # s
X_SCALE, S_SCALE = 5.0, 100.0    # kg/m3, mol/m3
SCALE = jnp.array([X_SCALE, S_SCALE])


def net(params, t):
    h = t[:, None] / T_SCALE
    for W, b in params[:-1]:
        h = jnp.tanh(h @ W + b)
    W, b = params[-1]
    return jax.nn.softplus(h @ W + b) * SCALE    # X and S, never negative


def X_nn(params, t):
    return net(params, jnp.array([t]))[0, 0]


def S_nn(params, t):
    return net(params, jnp.array([t]))[0, 1]


dX = jax.grad(X_nn, argnums=1)    # dX/dt
dS = jax.grad(S_nn, argnums=1)    # dS/dt
```

b) Code $r_X$ and $r_S$ at 301 collocation points, evenly spaced from 0 to 300 s, with `jax.vmap` (JAX; L11, L13) over $t_j$. Multiply $r_X$ by `T_SCALE / X_SCALE` and $r_S$ by `T_SCALE / S_SCALE`, so both are of order one.

c) Code $\mathcal{L}$ with $\lambda = 0.01$. Train with `optax.adam(1e-3)` (Optax; L11, L13) for 20,000 steps.

d) Evaluate the network at $t = 0, 5, \ldots, 300$ s and plot it with the measurements of experiment 5. How long did training take? What would you have to do to predict a sixth experiment?

## 3. Neural ODE
Consider the same balances, with the growth rate replaced by a network $\mu_\text{NN}(S)$:

$$
\frac{dX}{dt} = -\frac{F}{V}\,X + \mu_\text{NN}(S)\,X, \qquad
\frac{dS}{dt} = \frac{F}{V}\,(S_F - S) - \frac{\mu_\text{NN}(S)}{Y(S)}\,X
$$

Using Equinox, Diffrax and Optax, as in `l13-neural-dae.ipynb`, learn $\mu_\text{NN}$ from experiments 1 to 4:

a) Code the network below: `GrowthRate` of `l13-neural-dae.ipynb` (`eqx.Module`, `eqx.nn.MLP`: Equinox; L13), with $S$ as its only input.

```python
mu_scale = 0.05      # 1/s: sets the size of mu


class GrowthRate(eqx.Module):
    mlp: eqx.nn.MLP

    def __call__(self, S):
        out = self.mlp(jnp.array([S / 100.0]))[0]
        return mu_scale * jax.nn.softplus(out)    # mu >= 0


mu_net = GrowthRate(eqx.nn.MLP(
    in_size=1,
    out_size=1,
    width_size=16,
    depth=2,
    activation=jnp.tanh,
    key=jax.random.PRNGKey(0),
))
```

b) Code the balances with $\mu_\text{NN}$. Evaluate $\mu_\text{NN}$ and $Y$ at `jax.nn.softplus(S)` (JAX; L13), not at $S$.

Hint: softplus equals $S$ for $S > 5$ mol/m³ and is always positive. Without it, training can drive $S$ below zero, $Y(S)$ reaches zero, and the solver stops with "The maximum number of solver steps was reached."

c) Simulate the balances with `diffrax.diffeqsolve` (Diffrax; L13), using `diffrax.Tsit5()`, `dt0=0.5` and `diffrax.PIDController(rtol=1e-6, atol=1e-8)`.

d) Train on experiments 1 to 4 for 10,000 steps, as in `l13-neural-dae.ipynb` (`eqx.filter_value_and_grad`, `eqx.filter_jit`: Equinox; L13). The loss is the mean of $\left((\text{prediction} - \text{data}) / \sigma\right)^2$ over all their samples, where $\sigma$ is the standard deviation of their $X$ and of their $S$. The optimizer is Adam with a cosine schedule (Optax; L13):
